Amaliy sath (7-qatlam) va masofaviy ulanish

OSI modelining 7-qatlamida ishlaydigan Telnet va SSH protokollari tarmoq muhandislariga routerlar, switchlar va boshqa uskunalarga lokal konsol kabelisiz masofadan ulanish imkonini beradi. Bu ikki protokol funksional jihatdan o'xshash, lekin xavfsizlik darajasi keskin farq qiladi.

Cisco IOS konfiguratsiya asoslari

VTY liniyalari (Virtual Terminal Lines)

Cisco qurilmalarida masofaviy ulanishlar VTY (vty 0 4) liniyalari orqali boshqariladi. Har bir VTY liniyasi — bitta potensial masofaviy sessiyaga to'g'ri keladi. Standart konfiguratsiyada VTY liniyalari Telnet va SSH uchun ochiq bo'lishi mumkin, biroq transport protokolini aniq ko'rsatish xavfsizlik nuqtai nazaridan muhim.

vty 0 4 transport input ssh transport input telnet no transport input

SSH uchun zarur shartlar (Cisco IOS)

SSH ishlashi uchun: (1) hostname standart bo'lmagan nom bo'lishi kerak, (2) domen nomi (ip domain-name) belgilanishi lozim, (3) RSA kalit juftligi yaratilishi kerak, (4) AAA yoki local username/password sozlanishi shart. crypto key generate rsa buyrug'i asosiy qadam hisoblanadi.

Enable va enable secret farqi

enable password — ochiq matnda saqlanadi (xavfli). enable secret — MD5 xeshlash bilan saqlanadi (tavsiya etiladi). Agar ikkalasi ham sozlangan bo'lsa, enable secret ustunlik qiladi. Zamonaviy konfiguratsiyalarda faqat enable secret ishlatiladi.
