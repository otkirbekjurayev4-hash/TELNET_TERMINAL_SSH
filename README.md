# Telnet va SSH — Masofaviy ulanish laboratoriyasi

Bu loyiha GitHub Pages uchun tayyorlangan statik HTML/CSS/JavaScript laboratoriya sahifasidir.

## Ishga tushirish

1. `index.html` faylini brauzerda oching.
2. GitHub Pages orqali joylash uchun repository yarating.
3. Ushbu fayllarni repository ichiga yuklang.
4. GitHub → Settings → Pages → Branch: `main`, Folder: `/root` ni tanlang.
5. Save tugmasini bosing va berilgan havolani oching.

## Tuzilma

```text
/
├── index.html
├── README.md
└── .gitignore
```

## Eslatma

Loyiha build talab qilmaydi. React, Laravel yoki Node.js kerak emas. Faqat `index.html` yetarli.
